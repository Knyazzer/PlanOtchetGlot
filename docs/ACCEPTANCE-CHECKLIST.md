## 0. Подготовка тестовых ролей (5 минут, один раз)

В дампе донора не было руководителей — назначь их, чтобы проверить иерархию прав:

1. Войди как `admin@nexus.local` → **Персонал → Структура**
2. Назначь **руководителем отдела** «Отдел бренд медиа» — любого сотрудника отдела (запомни его email)
3. Назначь **директором департамента** «Бренд медиа департамент» — любого второго сотрудника этого департамента (запомни его email)
4. Найди сотрудника **Департамента персонала** (HR) и сотрудника **Финансового департамента** — запомни их email (для проверки модулей)

## 1. Путь обычного сотрудника (member)

Войти: любой рядовой сотрудник (не admin@nexus.local)

- [ ] После входа — «Главная», карточка **«Заполнить сегодня»**: выбрать формат, время, перерыв → Итого пересчитался → Сохранить → «✓ Заполнено»
- [ ] Выбрать формат «Отпуск» → появилось поле «По дату (период)» + чекбокс «Не трогать заполненные» → применить на 3 дня
- [ ] **Задачи**: создать задачу (название + исполнитель — обязательные; клиент с подсказками, тип-пиллы, минуты)
- [ ] Создать задачу с повтором «По будням» до конца недели → на доске появились экземпляры на каждый будний день, с бейджем ↻
- [ ] Завершить задачу с планом, но без факта → факт скопировался из плана автоматически
- [ ] Доска: переключить группировку **«По клиенту»** → колонки из клиентов; перетащить задачу в другую колонку → клиент сменился
- [ ] **«Мои колонки»**: создать колонку (Enter), переименовать (двойной клик), перетащить задачу, удалить колонку → задача осталась
- [ ] Представления: Таблица (сортировка кликами по заголовкам), Гант, Календарь (клик по дню создаёт задачу с датой)
- [ ] **Свод**: виден только свой отдел; выбрать чужой отдел → «Нет доступа»
- [ ] Клик по СВОЕЙ ячейке → карточка дня редактируется; по ЧУЖОЙ → только просмотр + задачи коллеги
- [ ] **Аналитика**: скоуп «Я» и «Команда» работают; «Компания» — отсутствует (нет права)
- [ ] **Команда**: всё дерево компании видно, себя подсвечен
- [ ] **Настройки**: только вкладка «Профиль и тема» (админ-вкладок нет)
- [ ] **Уведомления** (колокол): пусто или лента; после того как админ назначит ему задачу (см. §4) — появится запись
- [ ] Сайдбар: секции модулей департамента (для бренд-медиа: «Производство») с пометками
- [ ] Тёмная/светлая тема — переключаются, всё читаемо в обеих

## 2. Путь руководителя отдела (head)

Войти: руководитель из §0.2

- [ ] **Свод своего отдела**: видна вся сетка отдела (6 человек), агрегаты в подвале (часы/баллы/задачи)
- [ ] **Задачи** scope «Команда» (вкладка/фильтр team): видны задачи всего отдела, не только свои
- [ ] **Аналитика** скоуп «Команда»: данные по отделу (заполненность, нагрузка с цветными барами)
- [ ] Чужую ячейку Свода открыть → просмотр дня сотрудника + его задачи (но не редактирование)

## 3. Путь директора департамента (director)

Войти под директором из §0.3

- [ ] Свод: доступны ОБА отдела своего департамента (переключение в селекте)
- [ ] Аналитика «Команда»: охват — весь департамент

## 4. Путь админа

Войти: `admin@nexus.local`

- [ ] Видит всё: все отделы в Своде, скоуп «Компания» в Аналитике
- [ ] **Настройки → Роли и доступы**: видны 10 департаментов с грантами; снять галку модуля → у сотрудника департамента пропала секция в сайдбаре (перелогин/обновление); вернуть
- [ ] Сменить уровень модуля (например fin.budgets: «руковод.+») → у рядового финансиста бейдж «просмотр»
- [ ] **Настройки → Форматы дня**: изменить балл формата → строка «Действует с» = 1-е число текущего месяца; в Своде за МАЙ баллы НЕ изменились (версионирование!)
- [ ] Назначить задачу сотруднику из §1 → у того в уведомлениях появилась запись «назначил вам задачу»
- [ ] Персонал/База данных — доступны (у не-админов — нет)

## 5. Департаментные модули (КИТ 1)

- [ ] **HR** (сотрудник Департамента персонала): в Календаре может создать запись «Отпуск/Больничный» ДРУГОМУ сотруднику (тип hr_*) — сценарий С-3
- [ ] **Не-HR** (например, радист): создать hr-запись в календаре → 403/ошибка
- [ ] **Финансист**: в сайдбаре секция «Финансы»; модуль с editLevel=head у рядового — бейдж «просмотр»
- [ ] Сотрудник без департамента/фрилансер: только базовые пункты, секций модулей нет

## 6. Мобильная версия (сузить окно <768px или с телефона)

- [ ] Нижняя навигация: Главная · Задачи · Свод · Чаты · Ещё
- [ ] Свод = лента «Мои дни» (не сетка); клик по дню → карточка
- [ ] «Ещё» открывает остальные разделы + Уведомления/Тема/Выход
- [ ] Чаты открываются на весь экран
- [ ] Карточка дня на Главной удобна пальцем

## 7. Сквозное

- [ ] Свод/Аналитика за **май 2026** показывают реальные данные донора (например «Отдел бренд медиа»: 6 чел, 83 дня)
- [ ] Графики Аналитики рендерятся (recharts — после фикса)
- [ ] Изменение в одной вкладке видно в другой ≤30 сек (поллинг)
- [ ] Чаты: отправка/редактирование/прочитанность (WebSocket)
- [ ] Существующие модули не сломаны рестайлом: Проекты (реестр+Workflow+карточка WI с расходами), Треки, Календарь, Персонал

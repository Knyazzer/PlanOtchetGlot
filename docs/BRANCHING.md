# Стратегия ветвления Nexus

> Канон git-процесса проекта. Зафиксировано 2026-07-11 (ранее модель ветвления нигде
> не была задокументирована).

## Модель веток

```
knyazzer ──────┐
                ├──► dev ──(PR, аппрув только Влада)──► master ──► CD-автодеплой
daewoo-matiz ──┘
```

| Ветка | Назначение |
|-------|-----------|
| `knyazzer` | Рабочая ветка Влада (первый разработчик). Фичи пилятся здесь. |
| `daewoo-matiz` | Рабочая ветка второго разработчика. |
| `dev` | Интеграционная ветка. Сюда мерджатся `knyazzer` и `daewoo-matiz`, здесь гоняются тесты. |
| `master` | Прод. **Push в master = автодеплой** (GitHub Actions → GHCR → SSH на VDS). |

## Правила

1. **Каждый разработчик работает в своей ветке** (`knyazzer` / `daewoo-matiz`), не коммитит напрямую в `dev` или `master`.
2. **Интеграция через `dev`**: рабочие ветки мерджатся в `dev`, там прогоняются тесты (см. чеклист перед коммитом в `RULES.md §7`).
3. **PR `dev → master` аппрувит ТОЛЬКО Влад.** Никто другой не мержит в master.
4. **master — деплойная ветка.** Любой push в неё запускает CD. Не пушить недотестированное.
5. Порядковые номера PR отражены в сообщениях коммитов слияния (`… (#N)`).

## Историческая справка: squash-чистка (15 июня 2026)

Перед открытием репозитория на публичном GitHub вся история была **схлопнута в чистую**
(`chore: clean initial publish`, `80316f8`) — из истории удалены секреты (`JWT_SECRET`,
пароль БД и пр.). Репозиторий фактически начат заново: `80316f8` — корневой коммит без
родителя, старая (до-чисточная) история в него **не входит**.

**Следствия для безопасности:**
- Пуш `knyazzer` / `dev` / `master` **безопасен** — эти ветки содержат только чистую
  историю от `80316f8`. Старые секреты в них физически отсутствуют
  (проверено: `merge-base` чистой линии со старой историей пуст).
- ⛔ **Старые до-чисточные клоны/ветки (до 15 июня) пушить НЕЛЬЗЯ** — они содержат
  историю со старыми секретами, их push вернул бы секреты в публичный репозиторий.
  Полный бэкап до-squash истории хранится у Влада отдельно (вне этого репо).
- Плановая **ротация секретов** — `docs/SECRET-ROTATION.md` (старые значения считать
  скомпрометированными, пока не сменены).

## Порядок работы (шпаргалка)

```bash
# начать фичу
git checkout knyazzer && git pull
# … работа, коммиты …
git push origin knyazzer

# интеграция
git checkout dev && git pull
git merge knyazzer            # + daewoo-matiz по мере готовности
# прогнать тесты (RULES.md §7), затем PR dev → master (аппрув Влада)
```

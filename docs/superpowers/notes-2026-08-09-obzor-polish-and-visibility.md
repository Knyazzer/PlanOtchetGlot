## A. Полировка «Задачи на сегодня» (Обзор) — визуал

1. **Drag ещё не идеально гладкий — ОСТАВЛЕНО КАК ПРОБЛЕМА, чинить позже.** Уже переведено на div-grid sortable (паттерн support/ServersView), конфиг dnd-kit сведён 1:1 к support (дефолтный `useSortable`/`DragOverlay`, без модификаторов). Дёрганье на дропе всё ещё воспроизводится — разбираться отдельно (кандидат: `tasks` в Обзоре — ПРОИЗВОДНЫЙ список (filter+sort в родителе `DashboardPage`), из-за чего оптимистичный reorder и dnd-kit могут расходиться по кадрам; возможно, нужно локальное состояние порядка внутри компонента, а не пересорт в родителе).
2. **Обводка выпадашки при клике мигает.** Combobox в таблице сейчас безрамочный (`!border-transparent`); при клике на долю секунды мелькает рамка и пропадает. Нужно: при открытии показывать **устойчивую скруглённую обводку — так же, как у чипа «Время» (TimePicker)**. Свести focus/open-состояние Combobox к тому же виду, что у TimePicker (одинаковый «клик-контур»).
3. **Чип «Время»:** вместо текста-плейсхолдера «Время» показывать **`00:00`** (пустое значение = `00:00`, а не слово «Время»).
4. **Разделители столбцов:** тонкие вертикальные чёрточки **между столбцами ВНУТРИ строки** (короткие, только по высоте строки), а не сквозные вертикальные линии на всю высоту таблицы — визуально отделять колонки.

## B. Разделение видимости Стратегии (Кабинет vs страница «Стратегия») — СПЕКА

Наблюдение (баг): зашли с аккаунта директора департамента (она же руководитель эфирной группы). В Обзоре блок **«Стратегические цели отдела»** показывает цели ВСЕХ департаментов (коммерческий, дизайн и т.д.). Должно — только её область.

Правила (утв. Владом 2026-08-09):

- **В «Мой кабинет»/Обзор** (блок стратегических целей) человек видит инфо ТОЛЬКО по области, к которой относится — даже руководители и директора:
  - **Директор департамента** → цели своего департамента (глобальные цели самого департамента).
  - Если он **ещё и руководитель конкретного отдела(ов)** → плюс стратегические задачи этого(их) отдела(ов).
  - **Сотрудник** → цели своей области (свой отдел/департамент).
  - Принцип: в кабинете видно только «своё» (по членству/руководству), не по всей компании.

- **В разделе «Стратегия» (страница)** — разграничение по роли:
  - **Сотрудники** видят всё **только по своему департаменту**.
  - **Руководители и директора** видят всё **по всей компании**.

Текущее (что править): блок «Стратегические цели отдела» в Обзоре (`DashboardPage` → `DeptGoalsCard`) берёт `GET /strategic-goals` без сужения до области пользователя. Нужно сузить выдачу (по департаменту/отделам членства-руководства) для кабинета, и отдельно — правила видимости на странице «Стратегия» (сотрудник = свой департамент; рук/дир = вся компания). Уточнить/согласовать с текущим охватом в `routes/strategic-goals.ts` (там уже есть «директор — все», что для кабинета неверно — это правило скорее для страницы «Стратегия», и то только рук/дир).

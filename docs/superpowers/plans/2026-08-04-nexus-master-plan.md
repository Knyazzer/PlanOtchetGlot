## A. Кабинет сотрудника — 🔜 текущий фокус
- ✅ **Месячная сводка справа в «Мой кабинет» + дате-зависимый кабинет.** `MonthStrip` — вертикальный столбец месяца (кубик = тип дня из day-entries, навигация по месяцам, отметка «сегодня»); клик по дню → рабочий стол (задачи/план/события) считается на выбранную дату, кнопка «← Сегодня», создание задачи/события с датой дня (планирование на будущее). `DayFillCard` — проп `date`. *(коммит f517b9c)*
  - ⏳ вынести из day-entries **реальные цвета типов дня** (сейчас маппинг по ключу в `MonthStrip.FMT_COLOR`); ⏳ индикатор «заполни день» на непроставленных рабочих днях.
- 🟡 **График работы сотрудника (HR)** — спека `specs/2026-08-04-hr-schedule-and-status.md`. 
  - ✅ **A(1/3) фундамент** (коммит 50bd170): модель `WorkSchedule` (недельный паттерн + часы) + миграция + сид (office 5/2) + API `/work-schedule` (GET /me, GET/PUT :userId) + клиент (DayFillCard предзаполнение из графика, MonthStrip ожидаемый тип бледно). График = прогноз-подсказка, НЕ факт.
  - ✅ **A(2/3) HR-конфиг UI** (коммит a246581): `WorkScheduleEditor` в карточке сотрудника (Персонал) — 7 селектов типов дня + часы + перерыв → `PUT /work-schedule/:userId`. Смоук PUT/GET ок.
  - ✅ **A(3/3) единый статус + правки Влада 2026-08-05** (коммиты 0c2239e, 8a261fb):
    - ✅ presence `GET /work-schedule/presence` из `DayEntry`+графика; Пульс «кто работает» на реале (смоук: начал день → «В работе»).
    - ✅ **П1** форматы до 6 базовых (убраны shift_*/unpaid). ✅ HR-доступ к справочнику форматов (62c88a7).
    - ✅ **П2** DayFillCard → «Мой рабочий день»: тип из графика, автосейв (кнопки Сохранить убраны тут и в WorkScheduleEditor), большая кнопка Начать/Закончить + крупный живой таймер, время правится вручную.
    - ✅ **П3** баланс дня (недо/переработка) + месячный баланс. ✅ **П4** счётчики (кабинет MonthStrip-футер + Пульс «Мои часы»). ✅ **П5** выходные месяца (Пульс + футер).
    - ⏳ *хвост: «всё равно отметить рабочий день» для нерабочего дня — проверить; баланс за произвольный период (сейчас только текущий месяц).*
- ⏳ **Персонал — сплит «как плеер в support»** (П6): слева таблица, справа развёрнутая карточка — вместо оверлея. Отдельный шаг после A.

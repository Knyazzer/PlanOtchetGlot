## A. Кабинет сотрудника — 🔜 текущий фокус
- ✅ **Месячная сводка справа в «Мой кабинет» + дате-зависимый кабинет.** `MonthStrip` — вертикальный столбец месяца (кубик = тип дня из day-entries, навигация по месяцам, отметка «сегодня»); клик по дню → рабочий стол (задачи/план/события) считается на выбранную дату, кнопка «← Сегодня», создание задачи/события с датой дня (планирование на будущее). `DayFillCard` — проп `date`. *(коммит f517b9c)*
  - ⏳ вынести из day-entries **реальные цвета типов дня** (сейчас маппинг по ключу в `MonthStrip.FMT_COLOR`); ⏳ индикатор «заполни день» на непроставленных рабочих днях.
- 🧭 **График работы сотрудника (HR).** Новая модель + HR-конфиг: HR при найме задаёт график (5/2, офис/удалёнка, часы) → **тип дня по умолчанию**. Сотрудник отмечает **начало/конец дня**; self-смена только **больничный/отпуск**; остальное — руководитель; **командировка — из проекта**. → переделать MVP-виджет «Мой статус» (сейчас свободный выбор — заглушка).
- ⏳ **Единый статус/присутствие** (после графика) — свести с `dayFormat`/Сводом аккуратно (несущая логика отчёта).

## C. Календарь — механики (spec `calendar-mechanics-decisions`) 🧭/⏳
- ✅ **Overlap параллельных (§5)**: равные колонки, **зазор справа** для создания параллельного зажатием, гэп между колонками, nowrap-подписи + деградация при многих параллельных (пороги week/day). *(коммит 6b1543c)*
- ✅ **Drag-интерактив §6 (1/2)**: боковая карточка без затемнения (календарь виден/кликабелен), живой черновик в сетке (пунктир=создание/заливка=правка), двусторонняя связь (тянешь края/двигаешь обводку ↔ время в карточке), клик-в-пустоте закрывает, мини-пикеры якорятся у карточки. *(коммит e795765)*
- ✅ **Drag-интерактив §6 (2/2)**: **перенос силуэтом** (клик-удержание → силуэт к курсору, подсветка целевого слота, дроп меняет день/время с сохранением длительности; week межколоночно, day по времени); **якорение карточки** сбоку от обводки (справа/слева по месту); карточка гаснет на время переноса; клик<5px = открыть. *(коммит 2942014)* — **§6 закрыт.**
  - ⏳ мелочи §6 позже при желании: перенос события, у которого открыта карточка (сейчас блок скрыт обводкой → тащим обводку только в пределах дня); «резинка» пунктира при создании тянется только вниз.
- ⏳ **Задачи опционально в сетке времени** — время (старт–конец) как опц. параметр любой задачи (Task); задано → блок в дне/неделе.

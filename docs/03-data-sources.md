# TV Shifts — Источники данных (Google Sheets)

> **Актуальный документ.** Описывает реальную структуру источников данных, которую читает `syncService.ts`.

Все три таблицы доступны **только на чтение**. Запись в Google Sheets не производится (исключение: внутренние матрицы записываются через Drive API через `driveService.ts`).

### Статус через цвет ячейки

Явного столбца «Статус» нет. Статус определяется по цвету ячеек строки:

| Состояние | Определение |
|-----------|-------------|
| Все ячейки A–I без цвета | Проект **к реализации** — все данные утверждены |
| Одна или несколько ячеек подсвечены | Проект **предварительный** — подсвеченное поле ещё не точное |

Чтение цвета: `userEnteredFormat.backgroundColor` через Google Sheets API v4.

## 3. Матрица проекта (индивидуальный файл)

Отдельный Google Sheets на каждый проект. Ссылка хранится в реестре матриц (колонка B).

### Лист «СВОД» — шапка проекта

| Поле | Описание |
|------|----------|
| Матрица № | Уникальный ID (напр. ТВ2632550) |
| Клиент | |
| Название проекта | |
| Формат | |
| Дата | Основная дата проекта |
| Продюсер от ММ | |
| Менеджер по продажам | |
| Куратор от заказчика | |

### Лист «₽ СМЕНЫ» — специалисты и смены (ключевой)

**Строка 2** содержит фактические даты для колонок J–P:
- Даты рассчитываются относительно даты проекта (из СВОД)
- Диапазон: −3 дня до даты проекта, дата проекта, +3 дня после

**Строки 4+** — по одной строке на каждого специалиста:

| Колонка | Содержимое |
|---------|-----------|
| C | ФИО (полное имя — ключ для маппинга на аккаунт) |
| D | Смен ПЛАН |
| E | Смен ФАКТ |
| G | Функция на площадке (Режиссёр-постановщик, Звукорежиссёр и др.) |
| H | Формат смены (Смена до 8ч. и др.) |
| I | Тип занятости: `ШТАТ` = штатный сотрудник, `ИП 7%/8%/10%/СЗТ` = фрилансер |
| J–L | Дни ДО даты проекта → тип смены: **Застройка** |
| M | День проекта → тип смены: **Эфир** |
| N–P | Дни ПОСЛЕ даты проекта → тип смены: **Демонтаж** |

Значение `1` в ячейке = специалист работает в этот день. Пустая ячейка = не работает.

### Маппинг ФИО → аккаунт

1. Берём значение колонки C
2. Ищем точное совпадение по полю `full_name` в таблице `users`
3. Если совпадение не найдено — создаём уведомление «Неизвестный сотрудник»
4. Если `I = ШТАТ` → штатный сотрудник (учитывается в подсчёте смен)
5. Если `I = ИП/СЗТ` → фрилансер (отображается в карточке проекта, в смены не идёт)

## Сводная таблица: что откуда берём

| Данные | Источник |
|--------|---------|
| Список проектов | Таблица проектов (A–I) |
| Статус проекта | Цвет ячеек таблицы проектов |
| Ссылка матрица ↔ проект | Колонка «Ссылка на матрицу» таблицы проектов / ID из реестра матриц |
| Список матриц | Реестр матриц (колонка B) |
| Состав команды проекта | Лист «₽ СМЕНЫ» матрицы (колонка C) |
| Даты выходов | Лист «₽ СМЕНЫ», строка 2 (колонки J–P) + маркеры 1 в строках специалистов |
| Тип смены | Позиция колонки относительно даты проекта |
| Тип занятости | Колонка I листа «₽ СМЕНЫ» |

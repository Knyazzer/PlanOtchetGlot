# TV Shifts — Обзор проекта

## Что это

Веб-приложение для управления сменами, загруженностью и задачами ТВ-команды. Заменяет ручное ведение Google Sheets: автоматически импортирует данные о проектах, строит производственный календарь, считает смены и переработки.

## Для кого

**ТВ-департамент** производственной компании. Костяк команды:
- Видеоинженер
- Звукорежиссёр
- Оператор
- Режиссёр

В проектах также участвуют внешние специалисты (фрилансеры).

## Какую проблему решает

Сейчас учёт смен и загруженности ведётся вручную в Google Sheets. Чтобы понять, кто на каком проекте занят, нужно открывать десятки таблиц и переключаться между вкладками. Нет единого производственного календаря, нет автоматического подсчёта смен, нет уведомлений об изменениях.

## Ключевые возможности

- **Производственный календарь** — единый экран с проектами, командой и конфликтами по дням
- **Автоимпорт из Google Sheets** — данные о проектах и составе команд берутся из существующих таблиц, не требуя ручного ввода
- **Учёт смен** — автоматический подсчёт смен на месяц, переработок и отпусков по формуле
- **Уведомления** — изменения в расписании, конфликты, новые матрицы
- **Бэклог задач** — общий список задач для команды
- **Роли и доступы** — сотрудник, администратор, продюсер

## Деплой

- **Фаза 1**: локальная сеть (Docker Compose, доступ с любого компьютера в сети)
- **Фаза 2**: удалённый сервер, отдельный домен, доступ из любой точки

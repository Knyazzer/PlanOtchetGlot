## 0. Рамка

**Nexus** (`PlanOtchetGlot`, целевой домен `nexus.megapolis.team`, факт `nexus.knzteam.ru`) — Work OS компании и **центр экосистемы**: единственный провайдер входа (SSO) и источник справочника людей (`public.users`) для всех продуктов. Стек: pnpm-монорепо `apps/api` (Fastify+TS :4000) · `apps/web` (React+Vite+TS :5173) · `packages/db` (Prisma, Postgres :5433/тест :5434). Мультисхема: `public` (тонкая идентичность, пишет только Nexus) + `nexus` (~23 таблицы). Auth — self-hosted Supabase (GoTrue).

## 4. RBAC

Два кита: **функциональная** (базовый набор + департаментные модули, реестр `MODULES` в коде, гранты `DepartmentModule`) и **доступ** (`member<head<director` из оргструктуры, без отдельной таблицы ролей; `admin` — суперфлаг). Режимы `view/edit/manage`. ⚠️ **`requireRole` проверяет только `admin`** — прочие роли молча пропускают всех; честные гарды требуют доработки плагина auth. Возможен незакрытый гэп field-level фильтрации финансовых полей WI.

## 5. Сквозные правила и контракты (не сломать)

- **Raw SQL по схемам:** `nexus.*` — id `TEXT` (без каста); `public.users`/`auth.users` — `uuid` (каст `::uuid`/`::text`).
- **nginx allow-list ↔ server.ts:** новый префикс роута надо вручную добавить в `apps/web/nginx.conf`, иначе тихий `200`+`index.html` вместо JSON → краш (постмортем 2026-06-15).
- **React Query:** каждый `useMutation` инвалидирует все связанные ключи (включая «родителей»). Polling на многопользовательских страницах.
- **HTTP-коды:** GET 200/POST 201/PATCH 200/DELETE 204; 400`{error,details}`/401/403/404. Роут: `authenticate/requireRole` + Zod `.safeParse`.
- **SSO:** портал Nexus (`?redirect=`, токены в URL-хеше, whitelist, guard от петель); единый логаут `/?logout=1`.
- **Lifecycle:** заведение только через Nexus; статус бинарный (активный/архив), удаления нет; ⚠️ временный пароль открытым текстом; бан GoTrue не отзывает выданные токены.
- **`is_system_account`** — служебный `nexus-admin`, фильтруется во всех списках пользователей.
- **Безопасность:** HEAD чист; блокер — `JWT_SECRET`/пароль БД в git-истории (скомпрометированы → ротация, координация с Inventory). Средние: fail-open на `JWT_SECRET`, нет helmet, rate-limit не подключён к `/auth`, LAN-CORS в проде, контейнеры от root.

## Задачи — форма создания/редактирования (`TaskModal`)

| Поле | Текст подсказки |
|------|----------------|
| Тип | Влияет на иконку в ленте и фильтры. «Встреча» автоматически создаёт событие в Календаре. |
| Клиент | Необязательно. Используется в Аналитике и при фильтрации задач по клиенту. |
| Проект | Привязывает задачу к проекту компании. Задача появится в карточке этого проекта. |
| План, мин | Планируемое время на задачу в минутах. Учитывается в расчёте нагрузки сотрудника в Аналитике. |
| Факт, мин | Фактически затраченное время. Если при завершении задачи факт не указан — автоматически скопируется из плана. |
| Повторять | Создаёт отдельные копии задачи на каждый день по правилу. Каждая копия независима и помечается иконкой ↻. |
| Исполнитель | Кто выполняет задачу. Исполнитель получит уведомление о назначении. По умолчанию — вы сами. |
| Дедлайн | Срок выполнения. Просроченные задачи выделяются красным в ленте и попадают в блок дедлайнов на Главной. |

## Свод (`SvodPage`)

| Элемент | Текст подсказки |
|---------|----------------|
| Формат дня | Определяет тип рабочего дня и балл. Балл суммируется за месяц и влияет на KPI в Аналитике. |
| Минуты | Фактически отработанное время. Суммируется в подвале Свода по колонке и по строке. |
| Подвал — часы | Сумма отработанных минут по всем сотрудникам отдела за месяц, переведённая в часы. |
| Подвал — баллы | Сумма баллов форматов дня по всем сотрудникам. Баллы определяются настройками версии форматов. |
| Подвал — задачи | Количество задач, начатых в этом месяце у сотрудников отдела. |
| Статус дня (форма) | Тип рабочего дня. Определяет балл, который суммируется за месяц и влияет на KPI в Аналитике. |
| Перерыв | Длительность перерыва в минутах. Автоматически вычитается из рабочего времени при расчёте часов. |

## Аналитика (`AnalyticsPage`)

| Элемент | Текст подсказки |
|---------|----------------|
| Скоуп «Я» | Показывает только ваши данные — нагрузку, задачи, KPI. |
| Скоуп «Команда» | Данные вашего отдела. Руководитель видит весь отдел, рядовой сотрудник — только себя. |
| Скоуп «Компания» | Сводные данные по всей компании. Доступен только администраторам или по специальному праву. |
| Заполненность | Процент рабочих дней, в которые сотрудник заполнил Свод. Считается по производственному календарю РФ. |
| KPI | Рассчитывается по формуле: баллы × коэффициент формата / бизнес-дни периода. |

## Форматы дня (`SettingsPage` → вкладка «Форматы дня»)

| Элемент | Текст подсказки |
|---------|----------------|
| Балл | Вес формата в ежемесячном KPI. Изменение балла создаёт новую версию, начиная с 1-го числа текущего месяца. Прошлые данные не затрагиваются. |
| «Действует с» | Дата начала действия этой версии форматов. Предыдущие версии сохраняются и используются для расчёта архивных периодов. |

## Проекты (`ProjectsPage`)

| Элемент | Текст подсказки |
|---------|----------------|
| Статус | draft — в разработке; active — в работе; done — завершён; cancelled — отменён. Влияет на фильтры в реестре. |
| Work Item | Конкретная съёмка или задача в рамках проекта: дата, формат, локация, три роли. К WI можно привязать трек. |
| Расходы WI | Затраты по статьям внутри одного Work Item. Суммируются в бюджете проекта. |
| Клиент проекта | Клиент проекта. Если нужного нет в списке — добавьте через Персонал → Клиенты. |
| Ссылка на КП | Коммерческое предложение — ссылка на Google Docs, PDF или другой документ. |
| Бриф | Краткое описание: задача, цель, контекст. |
| Дата WI | Дата или период съёмки, вводится в свободной форме. |
| Формат WI | Производственный формат съёмки. Влияет на фильтры и отчёты по проектам. |
| Локация WI | Место проведения съёмки из предустановленного списка площадок. |

## Треки (`TracksPage`)

| Элемент | Текст подсказки |
|---------|----------------|
| Этап | Логический раздел трека. Задачи внутри этапа идут последовательно. Этап можно завершить отдельно. |
| Участники | Сотрудники, работающие над треком. Им видны все задачи трека в их ленте. |
| Дедлайн трека | Срок выполнения трека. Просроченные треки выделяются красным на карточке. |
| Привязать к WI | Опционально. Связывает трек с конкретной съёмкой в рамках проекта. Трек будет виден в карточке WI. |
| Статус трека | Активный — трек в работе; Завершён — все задачи выполнены; Архив — трек заморожен и скрыт. |

## Календарь (`CalendarPage`)

| Элемент | Текст подсказки |
|---------|----------------|
| Тип события | Встреча — событие с участниками и временем; Задача — личный to-do в Календаре; Личное — для планирования личного времени. |

## Роли и доступы (`SettingsPage` → вкладка «Роли и доступы»)

| Элемент | Текст подсказки |
|---------|----------------|
| Уровень доступа | «Просмотр» — только читать; «Редактирование» — создавать и изменять; «Руководитель+» — доступно только руководителям и выше. |
| Снять модуль | Убирает секцию из сайдбара всех сотрудников этого департамента. Изменение вступает в силу после обновления страницы. |

## Персонал (`PersonnelPage`) — только для администраторов

| Элемент | Текст подсказки |
|---------|----------------|
| Выдать доступ | Создаёт учётную запись для сотрудника с временным паролем. Пароль нужно передать лично — SMTP не настроен. |
| Табельный номер | Автоматически генерируется при создании: S### для штата, FL# для фрилансеров. |
| Деактивировать | Блокирует вход в систему и снимает табельный номер. Данные сотрудника сохраняются. |

## 📋 Функционал

### 🟠 Планировщик смены — пресет и синхронизация

Новая вкладка в карточке матрицы (`InternalShiftsPanel.tsx`) между «Команда» и «Производственные расходы». Дизайн задокументирован в `.superpowers/brainstorm/1183-1776628921/content/shift-planner-design-spec.md`.

- [ ] **Временные пресеты для ТВ/Телерадио** — Планировщик отображается для всех форматов и локаций. При открытии нового проекта с `project.format` ∈ {ТВ, Телерадио} блоки заполняются дефолтными временными диапазонами из хардкодного пресета. Для остальных форматов (Радио, Съёмки, Оффлайн, Менеджмент) пресета нет — блоки создаются пустыми.
- [ ] **Таймлайн-компонент** — CSS grid 4-cell (corner | headerScroll | namesScroll | tracksScroll), горизонтальный + вертикальный скролл только в `tracksScroll`, синхронизация JS scroll listener
- [ ] **Рендер блоков из `group_schedule`** — блоки (Сбор, Завоз, Монтаж, Эфир/копии, Демонтаж/копии, Вывоз) с абсолютными минутами, динамический диапазон (`min-60` … `max+60`), шаг 30 мин
- [ ] **Person-first строки** — одна строка на специалиста, тонкая линия-коннектор через все его блоки, greedy stacking при перекрытии
- [ ] **Drag-and-drop блоков** — перемещение целого блока + resize краёв; прямой DOM во время drag, `render()` только на pointerup
- [ ] **Попап даты блока** — клик (< 5px движения) → ◄ дата ► + кнопка «Закрыть»; шаг ±1440 мин
- [ ] **Резайз диапазона участника** — ручки на краях бара участника, зажаты диапазоном родительского блока, шаг 30 мин
- [ ] **«Начало эфира» — маркер-playhead** — вертикальная линия поверх timeline, перетаскивается в пределах Эфир-блока. Значение хранится в `group_schedule.efir.broadcastStart`. Двусторонняя синхронизация: тянем в Планировщике → обновляется поле в GroupDateBlock «Команда»; редактируем там → сдвигает playhead
- [ ] **Зум** — кнопки +/− (шаг ×1.3), диапазон 18%–600%; Ctrl+колесо с привязкой к курсору
- [ ] **Сохранение изменений** — PATCH `/status-rows/:id/group-schedule` для дат/времён блоков; отдельная схема для персональных диапазонов (решить: новый JSONB `shift_schedule` на `project_members` или расширить `field_approvals`)

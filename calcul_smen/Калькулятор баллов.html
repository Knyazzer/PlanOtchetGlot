Свои проекты

Проекты с грейдом ТВ/тех — умножаются на коэффициент сложности для каждого отдела.

Внешние проекты

Проекты для других отделов / клиентов — без грейда, по базовым коэффициентам смен.

Состав команд

ТВ-команда: режиссёр, звукорежиссёр, видеоинженер, оператор

Тех-департамент: руководитель, инженеры (можно добавить несколько)

Состав команд редактируется в коде (в переменной state.tvTeam и state.techTeam). В текущей версии — через UI пока не редактируется, чтобы сохранить простоту.

Как работает математика
Формулы:
свой проект: базовый коэф. смены × грейд проекта
внешний проект: базовый коэф. смены (без умножения)
внепроектная работа: коэф. активности × число дней
порог переработки: рабочие дни × множитель порога

Конкретные коэффициенты настраиваются в блоке «Настройка коэффициентов» выше и могут отличаться для ТВ и тех-команды.

## Обзор

Полная замена существующего `RegistryDetailModal` на новый дашборд-стиль. Модалка занимает `97vw × 92vh`, `max-width: 1280px`, фиксируется по центру экрана.

### Header
- Градиентный фон: `linear-gradient(135deg, #f8fafc, #eff6ff)`
- Название матрицы (bold 17px) + клиент (grey 13px) + статус-бадж (синий pill)
- Кнопки: `↻ Проверить`, `Изменить`, `Удалить` (красная рамка), `×`

### Global Footer (на всех вкладках)
- Только поле **Источник** с цветным бейджем (green = `projects_table`, etc.)
- Высота ~32px, фон `#f8fafc`, шрифт 11px uppercase

## Вкладка: Инфо

Три блока в строку (`grid-template-columns: 1fr 1fr 1.4fr`):

### Блок «О проекте»
Поля (label + value в строку):
- ID матрицы (monospace, серый)
- Ссылка (зелёный chip со значком 📊, открывает Drive)
- Юнит
- Формат
- Дата (bold)

### Блок «Команда»
- Продюсер
- Менеджер  
- Куратор

### Блок «Прогресс»
Два круговых SVG-диаграммы рядом, разделены вертикальной линией:

**Ганта** — пирог из N равных секторов (N = кол-во задач). Завершённые = зелёные (`#22c55e`), остальные = серые (`#e2e8f0`). В центре: процент. Под диаграммой: счётчик `X/N` + подпись «задач выполнено».

**Подтверждено** — placeholder (пунктирный круг, текст «скоро»). Будет отображать процент подтверждённых смен.

Диаметр SVG: `150×150`. Внутренний белый круг (donut hole) r=26.

## Вкладка: Смены

### Sub-tabs bar
- Всегда первым стоит **Свод** (заблокирован, не перетаскивается, `cursor: default`)
- Далее — вкладки смен (названия = имя смены), перетаскиваемые через HTML5 drag-and-drop
- Кнопка `+` для добавления смены

### Свод (сводная таблица по всем сменам)

HTML-таблица с `border-collapse: collapse`. Колонки:
```
| Смена (200px fixed) | ФИО | Должность | [глобальные даты...] |
```

Структура по секциям (одна секция = одна смена):
1. **`date-label-row`** — строка с подписями дат. Левая ячейка `rowspan=N+1` (info-card смены). Далее пустые ячейки ФИО/Должность, затем по одной ячейке на каждую глобальную дату с цветным бейджем типа дня.
2. **N строк `person-row`** — каждая: ФИО, должность, и в ячейках дат либо синий квадратик (есть смена) либо серая черта.
3. **`section-gap`** — строка-разделитель (12px высота, серый фон, верхняя граница).

**Info-card смены** (слева, `rowspan`):
- Название смены (bold)
- Даты диапазона (синий)
- Статус (pill)
- Локация
- Исп. продюсер

Типы дней (бейджи в `date-label-row`):
- Застройка — жёлтый (`#fef3c7 / #92400e`)
- Эфир — синий (`#dbeafe / #1d4ed8`)
- Дедлайн — красный (`#fee2e2 / #991b1b`)
- Съёмка — зелёный (`#d1fae5 / #065f46`)
- Прочее — фиолетовый
- Пусто — `—` серый

Одна и та же дата в разных сменах может иметь разный тип — это нормально, каждая секция независима.

### Индивидуальная смена (layout)

Двухколоночный layout: `220px (info) | flex:1 (table area)`.

**Левая панель — инфо о смене:**
Порядок полей:
1. Статус (pill-бейдж)
2. Время
3. Дата
4. Локация
5. Исп. продюсер
6. Лайн-продюсер

*Убрать:* заголовок «О смене», поля Название и Клиент.

**Правая область — таблица:**
Верхняя строка: toggle «Команда | Расходы» + кнопка «+ Добавить».

**Команда (таблица ФИО):**
Колонки: ФИО, Должность, [даты со dropdown-подписями], Подтверждено.

Шапка дат — кликабельная: dropdown с вариантами:
- Застройка / Эфир / Дедлайн / Съёмка + поле ввода кастомной подписи

**Расходы:**
Колонки: Услуга, Исполнитель, Сумма, Форм. оплаты, Комментарий.
Данные: API `/shift-expenses?projectId=...`

## Вкладка: Ганта

Layout: левая часть (460px) — список задач, правая — временная шкала. Вертикальный скролл синхронизирован между списком и барами (флаги `_lockV`). Горизонтальный скролл только в правой части.

**Список задач (левая):**
Колонки: №, Название (широкая), Ответственный, Дедлайн, Статус. Строки выровнены по высоте 38px с барами.

**Временная шкала:**
- Охват: ~2 месяца, `min-width: 1300px`
- Хедер: строка месяцев + строка дней (32px на день), выходные затенены
- Каждая строка — `g-row` с абсолютно позиционированным баром (`g-bar`)

**Взаимодействие с барами:**
- **Drag-to-create:** mousedown на пустой строке → тянешь → появляется ghost-бар → отпускаешь → создаётся задача
- **Drag-to-move:** mousedown на существующем баре → тянешь → перемещается
- Завершённые задачи: бар зелёный (`#bbf7d0 / #22c55e`), строка в списке с `opacity: 0.55`

Кнопка «+ Добавить задачу» в нижней панели.

## Вкладка: Заметки

Чат-стиль: аватар + имя + время + текст. Внизу — textarea + кнопка отправки.  
API: `GET/POST /matrix-notes?matrixId=...`

---

## Вкладка: Документы

Список файлов: иконка + название (ссылка) + дата + кнопка удаления.  
Кнопка «+ Прикрепить файл».  
API: `GET/POST/DELETE /matrix-documents?matrixId=...`

---

## Вкладка: Изменения

Хронологический лог (новые сверху).  
Каждая запись: аватар (цветной круг с инициалами) + имя + тег изменения (CREATE/EDIT/DELETE) + описание (`старое → новое`) + timestamp.  
API: `GET /change-logs?entityId=...&entityType=MatrixRegistry`

Теги:
- CREATE — зелёный
- EDIT — синий
- DELETE — красный

---

## API-маппинг

| Данные | Эндпоинт |
|--------|----------|
| Инфо матрицы | уже в `MatrixRegistry` из `/sync/data` |
| Члены команды | `/project-members?statusRowId=...` |
| Смены (ФИО + даты) | парсится из `shifts_cache` на `MatrixRegistry` |
| Задачи Ганта | `GET/POST/PATCH/DELETE /matrix-gantt?matrixId=...` |
| Заметки | `GET/POST /matrix-notes?matrixId=...` |
| Документы | `GET/POST/DELETE /matrix-documents?matrixId=...` |
| Расходы | `GET/POST/PATCH/DELETE /shift-expenses?projectId=...` |
| Изменения | `GET /change-logs?entityId=...` |

## Стили

Проект использует **inline styles** (без UI-библиотек). Мокап написан с CSS-классами — при интеграции классы нужно конвертировать в объекты `style={{...}}` или вынести в константы-объекты стилей в том же файле.

Исключение: сложные CSS-правила (`:hover`, `position: sticky`, `::before`) — для них использовать `<style>` тег внутри компонента или глобальный CSS через `index.css`.
